Problem Statement / Objective

Students today are overwhelmed with information but under-supported in processing it. Traditional study tools — flashcard apps, PDF readers, quiz websites — work in isolation and require significant manual effort to create study materials. Students spend hours summarising lectures, making flashcards, and hunting for practice questions when they should be spending that time actually learning.

Additionally, hiring a personal tutor is costly, and generic AI chatbots like ChatGPT are not designed specifically for structured academic study — they lack context management, persona adaptation, multi-format note generation, and a cohesive study workflow.

StudyMate AI solves this by being a single, cohesive AI-native study workspace where students can:

  • Paste a topic or upload a document (PDF/image) and instantly get structured notes in multiple formats
  • Generate unlimited quiz questions at different difficulty levels with explanations
  • Create flashcard decks for spaced repetition learning
  • Get personalised tutoring from an AI that adapts its teaching style (Socratic, ELI5, Academic, Coder)
  • Plan a full study schedule with a day-by-day breakdown of tasks

Target User & Use Case

👩‍🎓 University Students

Preparing for semester exams, summarising lecture PDFs, generating practice MCQs for self-testing.

📚 Self-Learners

Professionals upskilling in new domains (coding, data science, finance) who need structured content quickly.

🏫 High School Students

Studying for board exams, using ELI5 mode for complex topics, creating flashcards for vocabulary.

🧑‍💻 Developers

Learning new technologies using the Coder persona for code-focused, implementation-oriented explanations.

Primary use case: A student uploads a 20-page chemistry PDF → StudyMate generates Cornell-format notes, 15 MCQ questions, 20 flashcards, and a 7-day revision plan — all in under 2 minutes.

Expected User Experience & Outcomes

User Journey

  1. Sign up / Login — Email/password or Google OAuth via Supabase Auth → profile auto-created
  2. Dashboard — Greeted with stats (chats, notes, quiz avg score, study streak 🔥)
  3. AI Tutor — Ask a question, get a response in ≤3s (Groq speed). Switch personas. Attach a PDF or image. All chats auto-saved to sidebar.
  4. Notes — Paste topic or upload PDF → choose format + depth → rich structured HTML notes generated → download as PDF or Word
  5. Quiz — Pick topic, difficulty, count → answer MCQs → instant feedback + explanation → score saved to history
  6. Flashcards — Generate a deck by topic → 3D flip cards → rate each card → track known vs review
  7. Planner — Input subject + days + hours/day → get a complete day-by-day study plan

Outcomes

  • Students reduce time spent making study materials by 70–80%
  • Consistent daily usage encouraged by streak system and XP gamification
  • Multi-format notes accommodate different learning styles (visual, structured, reference)
  • Study plans create accountability and structure for exam preparation

Security & Best Practices

  • API keys never in frontend: All LLM API keys are environment variables injected at runtime into the backend container. The frontend only stores the Supabase anon key (which has no privileges — all access is controlled by RLS policies)
  • Row Level Security (RLS): Every Supabase table has RLS enabled. Users can only read/write their own rows — enforced at the database level, not just application code
  • Rate limiting: Both the Supabase Edge Function (15 req/min per user) and FastAPI backend (slowapi) have rate limiting to prevent abuse
  • Input sanitisation: All AI request parameters are sanitised and length-bounded before being sent to AI providers
  • JWT auth: All protected routes require a valid Supabase JWT token. Tokens are verified server-side
  • Docker non-root user: Container runs as a dedicated studymate user, not root
  • No secrets in version control: .env is gitignored. AWS secrets are injected via App Runner environment variables
